# EduNova Premium Student Dashboard

React + Vite lab project based on the supplied Modern UI Design using ReactJS experiment.

## Run
```bash
npm install
npm run dev
```
Open the URL shown by Vite, usually http://localhost:5173/

## Included
- Responsive premium dashboard
- Reusable React components and props
- State and event handling
- Light/dark theme
- Search
- Course progress
- Attendance visualization
- Academic performance chart
- Task add / complete / delete / filter
- Navigation sections
- Profile, analytics, calendar and settings pages
- Mobile responsive sidebar
- Toast feedback and modal form

## Build
```bash
npm run build
```
